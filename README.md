# 今天穿什么 · 温馨穿衣搭配助手

一个零依赖的单文件网页应用：根据**城市实时天气 / 温度 / 地区 / 性别 / 款式 / 颜色 / 鞋子**，给出整套穿搭建议，并展示真人换装效果。

在线预览：https://www.workbuddy.cn/space/d/7g8qQA7nT74uH0028M0kJg

## 功能

- **城市实时天气**：输入城市名（如「宁波」），调用 Open-Meteo 免费接口（无需 API Key）自动带出实时温度、天气代码、风速，并自动匹配天气 / 温度档位，可手动微调
- **多维度选择**：地区（华南/江南/华北/东北/西北/西南）、天气、温度、性别、款式、颜色、鞋子
- **穿搭规则库**：按温度档 × 性别输出上装 / 下装 / 配饰，叠加天气修正（雨雪防风防晒）
- **冲突提醒**：如「大热天穿雪地靴会很捂脚」「严寒天别穿凉鞋」
- **穿搭展示区 · 双模式**
  - 📷 真人实拍：8 张 AI 生成的写实穿搭照（男/女 × 4 款式），按所选颜色做色调映射
  - 🎨 卡通换装：纯 SVG 绘制的人物，衣服颜色/配饰（围巾、毛线帽、雨伞、遮阳帽）实时联动
- **收藏穿搭**：一键收藏当前搭配，本地保存、可删除
- **换配色**：奶油橘 / 樱花粉 / 抹茶绿 / 雾霾蓝四套主题，选择自动记住
- **随机一套**：选择困难时随机生成搭配

## 技术说明

- 单文件 `outfit-advisor.html`，HTML + CSS + 原生 JavaScript，**无框架、无构建步骤**
- 数据全部在前端计算，无需后端
- 主题通过 `body[data-theme]` + CSS 变量实现；收藏与偏好存 `localStorage`
- 响应式布局，适配手机 / 平板 / 桌面
- 天气数据来源：[Open-Meteo](https://open-meteo.com/)（Geocoding + Forecast API，免费非商用）

## 本地运行

直接用浏览器打开 `outfit-advisor.html` 即可。若想用本地服务器：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000/outfit-advisor.html
```

## 目录结构

```
outfit-advisor.html   单文件应用（唯一必需文件）
gen/                  AI 生成的人物素材（原图 PNG + 压缩后 JPG）
```

> 页面内使用的图片为图床直链，`gen/` 目录仅为素材备份，部署时不需要。

## 说明

AI 写真人物为固定 8 张（性别 × 款式），颜色通过画面色调映射呈现，并非衣服精确换色。
